# Security Policy

## Reporting a vulnerability

Please do not open a public issue for a security problem. Report it privately through GitHub's private vulnerability reporting for this repository: go to **Security → Report a vulnerability**.

Include the affected endpoint or file, the steps to reproduce, and the impact you expect. We will reply as soon as we can and will credit you in the fix if you wish.

## Supported versions

The `main` branch and the latest release receive security fixes.

## Secrets

Never include API keys, database URLs or other secrets in an issue or pull request. If one was exposed, rotate it first, then report it.
